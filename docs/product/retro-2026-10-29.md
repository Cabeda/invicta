# Retrospective: proposal to production

Sources: the current chat, `docs/ARCHITECTURE.md`, `GLOSSARY.md`, the native publisher, replay modules, page template and repository check configuration.

## Findings by severity

1. Outcome mismatch: the public page led with completed bus journeys and regional vehicle requests. Neither answers whether a scheduled bus leaves and arrives on time. Use explicit departure/arrival counts and retain missing trips in the denominator. Put detailed demand accounting behind an explanation.
2. Product hierarchy: the page mixed a public story, line explorer, policy editor, service model and evidence dump. Establish a single path from purpose to line, proposal, simulation, evidence and phased delivery.
3. Release guardrails: there was no package-level check command or CI workflow. Add deterministic checks for syntax, public module behavior and generated-asset contracts. Generated source copies diverged during editing; catch that mechanically rather than relying on reviewer memory.
4. Extension cost: line identity, asset locations and analysis assumptions were spread through the page. Put line registration and data loading behind one validated contract; keep line-specific study preparation separate from shared presentation.
5. Replay duplication: a request for 2D simulation was interpreted as a static planning map. Share the native trajectory engine between two actual renderers and verify the same scenario/time survives switching.
6. Tool economy: broad file scans and full generated HTML reads produced noisy outputs. Use the documented entry points and inspect compact summaries/hashes for generated data.

## Navigation

`docs/product/production-spec.md` defines the product acceptance criteria. `docs/ARCHITECTURE.md` defines module ownership. `GLOSSARY.md` defines trip, direction, proposal, replay and demand request. Native SUMO inputs and research remain traceable under their study adapters.

No global agent instructions or memory are changed. Mechanical release requirements belong in executable checks and CI. Scientific validity and the quality of the public explanation remain reviewer judgement calls.
