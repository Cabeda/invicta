# Combatentes native controls

This is a diagnostic evidence archive, not a promoted street proposal. The [results](../701-combatentes-native-fix-2026-10-30.md) explain the source failure, selected correction, retained strict misses and field limits.

`controls.json` and `evaluations.json` bind complete 127-service executions, both directions and all 6,024 stop calls. They retain exact-second and separate 60-second project assessments. Objects under `objects/` use compressed and decoded SHA-256 plus decoded byte length, verified by `trial_evidence.py`.

V6 matched controls reproduce the original network bytes and all native stop events. V7 is an unpromoted minimal-patch diagnostic with unrelated compiler drift. V8 is a superseded diagnostic whose fresh control rebuild was not identical to the original. The final V9 correction uses frozen compatible import bytes, pins connections from the exact archived V6 control, and requires a complete regional scope check. Failed import attempts and earlier model identities are retained rather than overwritten.

The recipe's `import_source` identifies the frozen intermediate import object by its full bytes. Its original netconvert header records the generating command; the source OSM archive is also verified. The V6 no-correction reconstruction establishes compatibility by exact output-network and 6,024-event equality. V9's model reports `import_mode: frozen_compiled_source` and no fresh-import command, so materialization is not misrepresented as a new OSM conversion.

The original failed public replay remains separate. Numerical passes here do not turn its trajectories into corrected trajectories, establish actual municipal signal timings, or qualify performance with ordinary traffic, passengers and vehicle blocks.
